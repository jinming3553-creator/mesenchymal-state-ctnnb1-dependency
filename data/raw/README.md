# Raw data

Raw public datasets are intentionally not committed to GitHub because several files are large.
Download them from the public repositories described in the manuscript Data availability statement and place them here using the filenames below.

## Broad NextGen
- `next_gen_expression.csv`
- `screen_gene_effect.zip`
- `model_metadata.csv`
- `screen_metadata.csv`
- `geneset_table_updated.csv`
- `next_gen_hotspot.csv`
- `next_gen_damaging.csv`
- `next_gen_copy_number.csv`

## Sanger organoids
- `data_RNAseq_ALL-organoids.csv`
- `data_covariates_ALL-organoids.csv`
- `41586_2026_10830_MOESM3_ESM.zip`

## HCMI
- `41586_2026_10806_MOESM3_ESM.zip`
- the 18 matched GI tumour/model `.h5ad` files used for the nine comparisons described in the manuscript.

The analysis scripts do not require raw data to be redistributed with the code repository.
